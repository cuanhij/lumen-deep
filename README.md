Lumen Deep is a deep-sea arcade game: pilot a small submersible through the dark trench, collect glowing pearls, dodge mines and anglerfish, and keep your oxygen up as you dive deeper. Every wave you clear, pick one of three upgrades — faster thrusters, a bigger oxygen tank, a pearl magnet, or a shield — and see how deep you can go on three lives.

## Run it

```sh
node serve.ts
```
